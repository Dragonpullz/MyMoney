# Plaid category vocabulary (full reference)

Categories observed across this workspace's transaction history, plus common
Plaid-taxonomy entries the agent may need when a question doesn't match a
preset in `.banksync-analysis/query.py`. Format: Title Case, words separated
by single spaces. Match with `-match` for substring filtering.

The most-used categories are kept inline in `.github/copilot-instructions.md`
so they're always in context. Use this file when something more obscure is
needed (charity, healthcare, travel, fees, etc.).
